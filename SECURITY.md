# Security policy

These are Gecka's rebranded builds of [RustDesk](https://github.com/rustdesk/rustdesk).

- **A vulnerability in the Gecka builds, packaging, or infrastructure:** report it privately to Gecka at [support@gecka.nc](mailto:support@gecka.nc). Please do not open a public issue.
- **A vulnerability in the underlying RustDesk code:** report it upstream, following the [RustDesk security policy](https://github.com/rustdesk/rustdesk/security/policy).

---

Signalez en privé toute faille des builds, du packaging ou de l'infrastructure Gecka à [support@gecka.nc](mailto:support@gecka.nc) (pas d'issue publique). Les failles du code RustDesk sous-jacent sont à signaler en amont, via la politique de sécurité de RustDesk.
