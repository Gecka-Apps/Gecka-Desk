# Contributing

Gecka Quick Support and Gecka Remote Support are Gecka products: rebranded builds of [RustDesk](https://github.com/rustdesk/rustdesk) for Gecka's own support operations. **We do not accept external contributions (issues or pull requests) to this repository.**

If you would like to improve the underlying software, please contribute upstream at [rustdesk/rustdesk](https://github.com/rustdesk/rustdesk). For anything specific to the Gecka builds, contact Gecka at [support@gecka.nc](mailto:support@gecka.nc).

---

Ce dépôt n'accepte pas de contributions externes. Pour améliorer le logiciel sous-jacent, contribuez en amont sur [rustdesk/rustdesk](https://github.com/rustdesk/rustdesk). Pour tout ce qui concerne les builds Gecka : [support@gecka.nc](mailto:support@gecka.nc).
